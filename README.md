# DesmosBigList
Turn matrix-based data storage into an easy to use view equivalent to accessing list items in a regular list.

## Usage
Use `biglist.py` as described in any Python project.
- `var_name` simply describes the variable name expected. It automatically handles formatting for you, so there is no need to add underscores manually.
- `plain_list` is the list you want to pass in. It can either be a flat list of numbers or a tuple containing three aligned lists.
- `max_mega_fragments` represents the maximum number of packed matrices in a single line. For most tasks you will never need to worry about this since usually only one partially-filled mega fragment is needed, but this provides an additional lever if you need each line to be reasonably-sized.
- `max_fragments` represents the maximum number of regular-sized lists in a single matrix element. Usually for smaller BigLists you won't need to fiddle around with it, but you may need to specify a smaller number less than 1024 if you end up getting OOM when inserting the string into Desmos or if DevTools flat-out stops working when pasting the list in.
- `max_list_size` just represents the maximum number of elements a standard Desmos list can hold. Currently 10,000, but maybe Desmos Team will increase this.

It is recommended to pipe the resulting string into a file instead of printing it into the console, especially for very large datasets.
- Note that at the present moment the output is a string, but it can easily be adjusted to pipe directly into a file instead of a string.

Then insert the resulting string into Desmos using `insert.js`
- `folderName` just represents the name of the folder, although you can rename the folder like any regular Desmos folder once inserted.
- `autoreplace` just represents whether or not you need the string to be reformatted to be more Desmos friendly. Although `insert.js` was designed for more general usage, when using it with `biglist.py` you should specify `false`.
- `txt` represents the actual string generated by `biglist.py`. It's recommended to type out "String.raw``" and pasting the string inside the backticks.

Note that if the string generated by `biglist.py` exceeds the Desmos graph save limit, you obviously cannot save the graph. At that point you could either just not save it or to reduce `max_fragments` and/or `max_mega_fragments` until each line fits the save limit and insert each line one at a time in separate graphs, followed by pasting the link of each graph into your main graph every time you want to use the main graph.
